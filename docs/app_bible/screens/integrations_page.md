# Presentation — IntegrationsPage

## Purpose

Allows shop administrators to set up or revoke third-party API configurations (Google Calendar, Google Contacts, SMTP mail fallback).

## Widgets / Visual Style

* **Integration Cards Grid**: Glowing cards for Google Integration (sign-in with Google, Calendar ID configuration) and Custom SMTP (host, port, username, password connection forms).
* **Verify Action Button**: Button to trigger interactive connection testing for SMTP servers.

## Uses Classes

* **ShopSettings** ([ShopSettings](../classes/shop_settings.md)): Active configs.
