# Presentation — QuotesListPage

## Purpose

Presents the list of estimates, session proposals, and price quotes drafted in the shop.

## Widgets / Visual Style

* **Search Field**: Live filter matching style or placement keywords.
* **Quote Price Ranges**: Prominent, gilded price range details (low/high estimated costs) in high-contrast styling.

## Uses Classes

* **Quote** ([Quote](../classes/quote.md)): Core estimate models.
