# Presentation — QuoteFormPage

## Purpose

Interactive workspace to compile multi-factor tattoo price estimates using standard studio formulas.

## Widgets / Visual Style

* **Parameters Form Grid**: Input controls for size, placements, detail densities, complexity, color, and coverup toggles.
* **Live Estimator Indicator**: Gilded indicator displaying estimated low/high price ranges dynamically calculating on every slider value change.

## Uses Classes

* **Quote** ([Quote](../classes/quote.md)): Calculated output.
