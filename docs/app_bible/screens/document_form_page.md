# Presentation — DocumentFormPage

## Purpose

Allows uploading new files (images, PDFs) and indexing them to a specific client.

## Widgets / Visual Style

* **Document Fields**: Text form fields for Document Title and Client Selector.
* **File Picker Selector Card**: Drag-drop or click box to trigger local OS file selection.

## Uses Classes

* **Document** ([Document](../classes/document.md)): Bound models.
