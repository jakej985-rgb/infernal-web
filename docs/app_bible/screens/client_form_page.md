# Presentation — ClientFormPage

## Purpose

Provides a data entry form to register a new client or modify an existing client's details.

## Widgets / Visual Style

* **Personal Info Fields**: Standard inputs for First Name, Last Name, Email, Phone, Pronouns, and Notes.
* **Responsive Form Layout**: Centered card design matching the gothic colors.

## Uses Classes

* **Client** ([Client](../classes/client.md)): Managed entity.
