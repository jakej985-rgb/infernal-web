# Presentation — DocumentsListPage

## Purpose

Enables staff members to upload, search, filter, and review shop documents (consent forms, ID scans, work pictures).

## Widgets / Visual Style

* **Upload Trigger (Floating Button)**: Themed crimson button navigating to document creation.
* **Search Bar & Filter Chips**: Input box to search items and ChoiceChips to filter by document type (ID Scan, Consent Form, Work Pic).
* **Document Cards Grid**: Styled cards with custom leading icons depending on document type (badge icon for ID, assignment icon for Consent Form, camera for pictures) with corresponding colored badges.

## Uses Classes

* **Document** ([Document](../classes/document.md)): File registry entries.
