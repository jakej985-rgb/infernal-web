# Presentation — AppointmentDetailsPage

## Purpose

Displays detailed, high-contrast information about a specific appointment slot.

## Widgets / Visual Style

* **Status Badge Header**: Prominent, colored status indicators (scheduled, in-progress, completed, cancelled, no-show).
* **Details Table Card**: Clear listings for Client details, executing Artist, pricing type, deposit, and service specifications.
* **Action Buttons**: Complete inline tools to begin session, complete checkouts, or edit booking fields.

## Uses Classes

* **Appointment** ([Appointment](../classes/appointment.md)): Rendered on the sheet.
