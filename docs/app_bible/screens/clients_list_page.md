# Presentation — ClientsListPage

## Purpose

Displays the list of clients / customers registered in the multi-tenant database.

## Widgets / Visual Style

* **Search Bar Filter**: Standard field to instantly search and filter clients by name, phone, etc.
* **Responsive Layout Grid**: High-contrast tiles mapping client avatars, full name, phone number, and status chip indicators.
* **Hamburger Menu**: On mobile viewports, displays a leading hamburger icon triggering the parent `AppShell` drawer navigation.

## Uses Classes

* **Client** ([Client](../classes/client.md)): Directory elements.
