# Presentation — UserListPage

## Purpose

Presents the list of staff users (Artists and Admins) registered within the shop's multi-tenant organization boundaries.

## Widgets / Visual Style

* **Staff Roster Grid**: High-contrast listings presenting display names, system role (Admin/Artist), hourly rate, and active status.
* **Inline Actions**: Navigation to user form to edit profiles or register a new staff member.

## Uses Classes

* **User** ([User](../classes/user.md)): Roster components.
