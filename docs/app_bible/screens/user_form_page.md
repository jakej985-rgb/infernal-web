# Presentation — UserFormPage

## Purpose

Enables creating new staff members or modifying an existing staff profile's roles, pricing ratios, and details.

## Widgets / Visual Style

* **Profile Form fields**: Styled text fields for Email, Username, Display Name, and Hourly Rate.
* **Role selector Dropdown**: Form control to select system permissions (Admin/Artist).

## Uses Classes

* **User** ([User](../classes/user.md)): Target managed profiles.
