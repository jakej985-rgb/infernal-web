# Theme & Styling — The Gothic-Neon Style Guide

The Infernal Ink & Steel Suite rejects standard corporate SaaS aesthetic, operating under a customized, immersive dark-industrial design layout referred to as **The Infernal Engine**.

---

## 🩸 Color Tokens

The visual palette matches dramatic, high-contrast gothic themes backed by subtle modern neon plate highlights:

```text
Color Name     | Hex Code  | System Purpose
---------------|-----------|------------------------------------------------
Void Black     | #0D0D0D   | Universal backdrop, dialog canvas.
Charcoal Grey  | #1A1A1A   | Primary card backgrounds, hover boundaries.
Blood Red      | #990000   | Primary accent highlights, headers, alerts.
Gilded Gold    | #D4AF37   | Secondary headers, special numbers, active highlights.
Arcane Purple  | #4B0082   | Consultative features (Calculators, Estimators).
```

---

## 💀 Typography

Standard system text is split into two distinct fonts to balance legibility with raw thematic atmosphere:

* **Cinzel / Cinzel Decorative**: Headings, titles, metric numbers, and major splash typography. Renders a timeless, stone-carved, gothic profile.
* **Roboto Mono**: General listings, data grids, timestamps, form text parameters, and numerical stats. Renders a precise, technical look.

---

## 🖤 UI Layout Components

Layout elements mimic physical tactile steel plates, layered canvas cards, and glowing mystical runes:

### NeonPlate Borders

Custom bordered container panels styled with subtle colored dropshadows (e.g., Blood Red glow for timeline appointments, Gold glow for Admin panels, Purple glow for Quote estimates). This draws distinct visual zones.

### Card Elevations

Primary metrics and timeline schedules are containerized on layered elevation grids (e.g., Void Black base, Charcoal cards, and Charcoal dialog modals) to deliver a clear dimensional hierarchy.

### Thematic Phrasing

All user-facing elements use immersive terminology rather than standard operational jargon:

* Client Registration → **Inscribe Soul**
* Appointment List → **Rituals Timeline**
* Quote Calculator → **Scribe Scroll**
* Audit Log → **System Karma Ledger**
* Waitlist Drawer → **Purgatory**
* Analytics Reports → **Read Omens**
