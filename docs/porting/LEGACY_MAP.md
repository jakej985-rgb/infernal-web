## 6. Business Rules

### 6.1 Quote Calculator Logic
```
baseHours = 0.5 + (area × 0.05 × (coverage/3))
avgComplexity = (line + shading + color + difficulty) / 4
complexityMultiplier = 0.8 + (avgComplexity × 0.4)
estimatedHours = baseHours × complexityMultiplier × (isCoverUp ? 1.5 : 1)
variance = ±20%
price = hours × hourlyRate (enforce shopMinimum)
deposit = 20% of priceLow
```

### 6.2 Authorization
- **Admin**: Full access
- **Artist**: Own appointments, limited client access

### 6.3 Sync (ISyncEntity)

## 8. Gotchas & Technical Debt

1. **Dual Repository Pattern**: Some repos use EF Core (`AppDbContext`), others use raw SQLite (`AppointmentRepository`)
2. **Missing DisplayName**: `User` entity exists but DisplayName is mapped to Username
3. **Denormalized ClientName**: `Appointment.ClientName` duplicates `Client.FullName`
4. **DateTime vs StartTime**: `Appointment.DateTime` aliased as `StartTime` via `[NotMapped]`
5. **Duplicate Auth attribute**: `ClientsController` has `[Authorize]` twice
6. **Mixed async/sync**: Some repos async, some sync
7. **Column migrations**: `EnsureColumnExists` manual migrations in repos
8. **React SPA**: ClientApp exists but primarily uses Razor Pages
